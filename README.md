A single hilarious one-liner about an AI agent that quits to become a poet — now it only answers in haikus and bills by the syllable.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or to the path given as the first argument). The output is deterministic: every run writes the exact same 95-character line.
